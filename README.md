# Tagalog-to-English Dictionary for Kindle

A Tagalog-to-English dictionary optimized for Kindle e-readers. Look up Tagalog words while reading on your Kindle.

## Features

- **42,730 unique Tagalog words** with English definitions
- **Verb conjugation support**: Automatically recognizes all three Tagalog verb aspects (progressive, completed, contemplated)
- **Ligature inflections**: Supports Tagalog `-ng` and `-g` ligature forms for seamless lookups
- **Multiple definitions**: Words with multiple meanings show labeled definitions (A, B, C, etc.)

## Quick Start

### Download Pre-built Dictionary

Check the [Releases](../../releases) page for pre-built `.mobi` files, or build from source below.

### Build from Source

**Requirements:**
- Python 3.10+
- [Calibre](https://calibre-ebook.com/download) (for .mobi generation)

```bash
# Install Calibre (provides ebook-convert)
brew install calibre        # macOS
sudo apt install calibre    # Linux

# Install the Python package
pip install -e .

# Build HTML only
./scripts/build.sh

# Build HTML and .mobi
./scripts/build.sh --mobi
```

The generated `.mobi` file will be in `dist/dictionary.mobi`. Copy it to your Kindle's `documents` folder.

## Development

### Setup

```bash
# Create virtual environment
python -m venv .venv
source .venv/bin/activate

# Install with development dependencies
pip install -e ".[dev]"
```

### Running Tests

```bash
# Fast tests only
pytest -m "not slow"

# All tests including production regression
pytest
```

### Project Structure

```
src/tagalog_dict/      # Main package
├── conjugation.py     # Verb conjugation extraction (sacred regex)
├── inflections.py     # Ligature and verb inflection XML
├── formatter.py       # Kindle HTML generation
├── parser.py          # JSON dictionary loading
├── pipeline.py        # Conversion orchestration
└── cli.py             # Command-line interface

tests/                 # Test suite
├── snapshots/         # Golden master test data
└── test_*.py          # Unit and integration tests

scripts/               # Build automation
├── build.sh           # Main build script
└── extract_conjugation_samples.py

data/                  # Source dictionary data
dist/                  # Generated output (HTML, .mobi not tracked)
res/                   # Kindle configuration files
```
